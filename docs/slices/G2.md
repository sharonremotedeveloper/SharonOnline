# Slice G2: Google Calendar busy times as a hint

Branch: `feature/claude-financial-core` · ERR block: 310.

## Behaviour

- `generate_teacher_slots(..., include_external_busy=False)`. Only `TeacherSlotsView` (the public listing) passes `True`; reserve, reschedule and checkout keep database truth. Composes with the generic `blocked_intervals` hook (Eskom can plug in later).
- **events.list, not freeBusy.query**, as plan section 3.4 allows: freeBusy cannot tell our lesson events from the tutor's own. `sync_booking_to_teacher_gcal` now stamps `extendedProperties.private.sharon_booking_id`; events carrying it are ignored by the hint, so our own lessons are not double counted (the slot shows `booked` from the database instead of vanishing). Cancelled, "free" (transparent), declined and `workingLocation` events are ignored; all-day events block the tutor's local days.
- `reconcile_teacher_gcal_task` (every 30 min) now only fans out one `sync_tutor_busy_task` per tutor (operational, connected, `block_busy` on); it returns `{'queued_tutors': n}` (was `reconciled_tutors`).
- **Fails open:** any Google, token or timezone problem leaves the last good hint (7200 s TTL) and the task returns `'unavailable'`; an unreadable cache hides nothing; `block_busy=False` or a revoked credential is checked live, so turning the toggle off takes effect at once and the next sync clears the cache.
- `fetch_freebusy` was removed (unused); `GOOGLE_CALENDAR_SCOPES` is unchanged (`calendar.events` covers events.list).
