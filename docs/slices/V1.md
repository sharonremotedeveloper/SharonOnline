## 1. Scope & Objective

Replace legacy single-host Zoom S2S OAuth room creation with Zoom Video SDK JWT token generation:
- Pure stateless HMAC-SHA256 JWT tokens conforming to Zoom Video SDK specifications.
- Deterministic session topic name `lesson-<booking_id>`.
- Strict role mapping: Tutor = Host (`role_type: 1`), Student = Participant (`role_type: 0`), Staff = Co-Host (`role_type: 1`).
- Enforces Decision **D-8**: `cloud_recording_option: 0` (no cloud recording).
- Clamped token TTL between 1800s (30m) and 172800s (48h), defaulting to 7200s (2h).
- Time window enforcement: classroom open window is `[start - 15m, end + 30m]`.
- Production security guard in `backend/config/settings/guard.py`: enforces that `ZOOM_VIDEO_SDK_SECRET` is at least 32 characters (preventing RFC 7518 insecure HMAC key warnings) and verifies symmetric credential configuration.

## 2. Key Files Touched / Created

- `backend/apps/integrations/services/video_sdk.py`:
  - `generate_video_sdk_token()`: Signs HS256 JWT payload with claims `app_key`, `version: 1`, `user_identity`, `iat`, `exp`, `tpc`, `role_type`, `cloud_recording_option: 0`.
  - `decode_video_sdk_token()`: Verifies and extracts JWT payload.
  - `resolve_role_for_booking()`: Authorizes parties and maps tutor to 1, student to 0, staff to 1.
  - `validate_booking_time_window()`: Enforces 15-minute lead time and 30-minute grace window.
  - `is_video_sdk_configured()`: Helper checking configuration presence.
- `backend/config/settings/base.py`:
  - `ZOOM_VIDEO_SDK_KEY`, `ZOOM_VIDEO_SDK_SECRET`, `ZOOM_VIDEO_SDK_SESSION_VALID_SECONDS`, `ZOOM_VIDEO_SDK_OPEN_MINUTES_BEFORE`.
- `backend/config/settings/guard.py`:
  - `validate_production_settings()`: Requires `ZOOM_VIDEO_SDK_SECRET` to be 32+ characters, ensures key and secret are provided together, and satisfies Zoom credential requirements.
- `backend/tests/test_zoom_video_sdk_service.py`:
  - 17 unit tests covering token generation, claims, expiration bounds, role resolution, and window enforcement.
- `backend/tests/test_settings_guard.py`:
  - 4 tests for production guard Video SDK validation.
