## Design decisions
- Window rule: whole minutes, `end > start`, at least 25 minutes (NOT multiples of 25/30: the generator steps 30 minutes inside any window), no cross-midnight, max 70 rows.
- Fall-back repeated hour is not offered twice (plan rule: first fold only), so on that day ~1 hour of real time inside a window is not listed.
- Invalid stored timezone: no slots + error log with ids; availability writes answer 400 `timezone`. No data migration of bad values (none found in code paths; admin `User.clean` now blocks new ones).
- Conflicts are judged against the WHOLE proposed schedule (weekly + overrides + time off), for CONFIRMED lessons not yet ended.
- Capture-time notice only applies while `now < start` (ERR-213).
