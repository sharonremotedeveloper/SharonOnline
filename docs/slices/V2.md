## 1. Scope & Objective

Expose the session token issuance endpoint: `GET /api/v1/bookings/<id>/video-token/`:
- **Strict Authorization First (Anti-Status-Oracle):** Only the assigned tutor, assigned student, or admin staff can call this endpoint; third parties receive `403 Forbidden` (`code: forbidden`) without learning booking status or details (ERR-196).
- **Status Allow-list:** Only `confirmed` and `in_progress` bookings open a classroom. `pending_payment` (unpaid) and settled/terminal lessons (`completed`, `disputed`, `student_no_show`, `teacher_no_show`) are rejected with `409 Conflict` (`code: classroom_unavailable`).
- **Cancellation Gate:** Cancelled bookings return `409 Conflict` (`code: booking_cancelled`).
- **Time Window Gate:** Bookings outside the $[T-15\text{m}, T_\text{end}+30\text{m}]$ window return `409 Conflict` (`code: outside_lesson_window`).
- **Throttle:** Scoped rate throttling (`zoom_video_token: 120/hour`).
- **Caching:** `Cache-Control: no-store` header prevents token leakage or caching in downstream proxies.
- **Typed Schema:** Fully typed `VideoTokenSerializer` with `@extend_schema` documentation.
