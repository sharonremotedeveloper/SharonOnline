# Slice F2 — In-App Notification Centre UI

Branch: `feature/f2-notification-centre-ui` · ERR block: 340 · dependency: N1b.

## Overview
Implements the in-app notification centre in the Next.js 16 frontend, consuming the N1b DRF API:
- `GET /api/v1/notifications/`
- `GET /api/v1/notifications/unread-count/`
- `POST /api/v1/notifications/<id>/read/`
- `POST /api/v1/notifications/read-all/`
- `GET|PATCH /api/v1/notifications/preferences/`

## Key Components
1. `Navbar.tsx` integration with `NotificationBell`:
   - Accessible bell trigger with dynamic unread count badge.
2. `NotificationDrawer.tsx`:
   - Flyout list of notifications with category indicators, relative timestamps, and unread visual markers.
   - Single item read on click + "Mark all as read" button.
3. `NotificationPreferencesModal.tsx`:
   - Category preference toggles with mandatory locks.
4. `useNotifications` hook:
   - Jittered visibility-aware polling (pauses when browser tab is hidden).
5. Comprehensive tests in `frontend/test/notifications.test.ts`.
