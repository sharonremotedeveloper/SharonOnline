## 1. Scope & Objective

Deliver the Next.js embedded live classroom running 100% in-browser via Zoom Video SDK (`@zoom/videosdk`):
- **Dynamic Client Integration:** Lazy-imports `@zoom/videosdk` on client mount to avoid SSR issues.
- **Pre-Join Stage:** Clean staging card showing lesson partner, WebRTC HD indicator, role-aware CTA button ("Enter Classroom" for student vs. "Open Classroom as Host" for tutor), and AV Device Settings.
- **Active In-Call Video Canvas:** Self preview picture-in-picture (PiP) and remote peer video canvas with auto-rendering and stream tracking.
- **Classroom Control Bar:**
  - Microphone mute/unmute toggle (`isAudioMuted` state with clear visual styling).
  - Webcam camera on/off toggle (`isVideoOff` state).
  - Screen share toggle (`isSharing` state; hidden gracefully on mobile).
  - AV Device Selection modal toggle: allows switching cameras, microphones, and speakers live via `mediaStream.switchCamera()`, `mediaStream.switchMicrophone()`, and `mediaStream.switchSpeaker()`.
  - Leave Room button: cleanly stops all tracks, leaves session, and triggers `onLeave` callback.
- **Mobile Responsive Design:** Sized for 320px+ viewports without horizontal scrolling, touch-friendly padding, responsive PiP layout, and collapsible secondary actions.
- **Hardware Readiness Check (`HardwareCheckModal.tsx`):** Removed simulated latency (`Math.random()`), replaced with real HTTP roundtrip measurement against server endpoint.
- **Error Handling & "Too Early" State (`videoSdk.ts`):** Clear mapping of server error codes to human-readable explanations (e.g. `outside_lesson_window` -> "The classroom is not open yet. It opens 15 minutes before the lesson starts.").
